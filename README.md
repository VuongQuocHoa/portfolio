## 🚀 1. How to View & Run Locally

### Option 1: Direct Browser Access (Zero Installation)
Simply double-click `index.html` in your browser (Chrome, Edge, Brave, Firefox, or Safari).

### Option 2: Local HTTP Server (Recommended)
Run via PowerShell or Terminal:

```bash
# Using Python (standard):
python -m http.server 3000

# Or via Node.js:
npx serve -l 3000
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser.

## 🖨️ 2. How to Export ATS A4 PDF Resume for Applications

The portfolio features a specialized `@media print` CSS engine calibrated for standard A4 company applications:
1. Open the portfolio in your browser: **[vuongquochoa-portfolio.onrender.com](https://vuongquochoa-portfolio.onrender.com/)**.
2. Click **"Export PDF / Print"** on the top navigation bar (or press **Ctrl + P** / **Cmd + P**).
3. Set **Destination**: Choose **"Save as PDF"**.
4. Configure Print Options:
   - Paper Size: **A4**
   - Margins: **Default** or **Minimum**
   - Background Graphics: **Checked (On)** to preserve crisp borders and badges.
5. Click **Save**. You will receive an immaculate, clean ATS-formatted PDF resume without navigation buttons or web UI clutter.
