04. TECHNICAL INTERVIEW HIGHLIGHTS (ARCHITECTURAL DEEP-DIVE)

Q1: How do you eliminate latency bottlenecks when executing real-time AI vision inference on high-frame-rate video feeds?
Architecture Solution: In the Edge AI Predict Mass project, the industrial camera captured at 60 FPS (~16.6ms per frame) while the segmentation neural network required ~28ms. A naive synchronous approach led to ballooning frame queues and crippling UI lag. I architected a Decoupled Asynchronous Multi-threaded Pipeline: an independent high-priority Camera Grabber thread pushes the freshest frame into a non-blocking circular buffer, while a parallel Inference Worker thread processes strictly the latest frame, cleanly dropping stale intermediates. Parallelizing ArUco marker pose estimation with deep segmentation eliminated 100% of accumulated latency, achieving a buttery-smooth 60 FPS display with sub-17ms latency.
Q2: What was your strategy for Model Quantization and running edge inference on resource-constrained hardware?
Architecture Solution: To deploy computer vision models on embedded CPU hardware without requiring power-hungry dedicated GPUs, I designed an automated Post-Training Quantization (PTQ) workflow using ONNX Runtime. By calibrating weight matrices and activation ranges against representative domain samples, FP32 floating-point values were mapped to 8-bit integers (INT8). This shrank model memory footprint by 50% (down to 6.2 MB), halved memory bus bandwidth consumption, and unlocked a 1.8x inference speedup by capitalizing on OpenVINO SIMD vector extensions.
Q3: How do you architect robust LLM / Generative AI streaming integrations for production web clients?
Architecture Solution: Connecting frontend clients directly to third-party LLM endpoints triggers critical CORS violations and leaks secret API tokens. In the Coze AI Agent system, I engineered a zero-dependency native Node.js reverse proxy and Vercel Serverless Edge handler. To handle Server-Sent Events (SSE) streaming seamlessly, I implemented an inline Deduplication Stream Parser that resolves duplicate text tokens between conversation.message.delta and completed events while stripping internal system OAuth artifacts. This guaranteed sub-150ms time-to-first-byte (TTFB) and real-time typewriter typography without flickering.
